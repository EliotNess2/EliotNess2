### ✨ Projet phare : ArtFolio26

Portfolio en ligne pour une céramiste, réalisé en 3 Blocs de compétences : front-end HTML5/CSS3/Bootstrap, back-end **PHP natif en MVC maison** (sans framework, PDO/MySQL) et une API REST/JSON.

- 🔒 Sécurité : requêtes préparées, échappement systématique, CSRF, sessions durcies, contrôle d'accès par rôle
- ✅ 38 tests PHPUnit (unitaires + intégration)
- ♿ Accessibilité pensée dès la conception (contrastes WCAG, navigation clavier, alternatives textuelles)

👉 [github.com/EliotNess2/artfolio26](https://github.com/EliotNess2/artfolio26)
